# 📝 React Task Manager

A simple **React task management application** with support for creating, editing, deleting, and completing tasks. Tasks are persisted in `localStorage` so that they remain after a page reload. The app also supports viewing completed tasks separately.

---

## ✨ Features

- ➕ **Add new tasks**  
- ✏️ **Edit existing tasks**  
- 🗑️ **Delete tasks**  
- ✅ **Mark tasks as completed / incomplete**  
- 📂 **View completed tasks separately**  
- 💾 **Persistent storage using `localStorage`**  
- 🌗 **Light and dark mode support**  

---

## 🛠️ Tech Stack

- ⚛️ **React**  
- 🌐 **React Router DOM**  
- 🎨 **Tailwind CSS**  
- 💾 **Local Storage**  

---

📝 Usage

Navigate to /tasks to view your current tasks.

Click ✏️ Edit on a task to update it.

Mark tasks as ✅ complete using the checkbox.

Navigate to /completed to see completed tasks.

Add new tasks via the /task-form page.

⚠️ Notes

Tasks are stored in the browser's localStorage.

Completed tasks are filtered and displayed separately.

Tailwind CSS is used for styling, including dark mode support.
